ルール設定モジュール

API設定

二期追加機能 NEW

二期では、開放プラットフォームに「AI分類」が追加されます。1 ファイルの帳票タイプだけを判定し、案件の作成やワークフローの起動は行いません。

追加内容
AI分類（送信） 業務シーンと 1 ファイルを送信し、分類タスク ID を受け取ります。受付は非同期です。
AI分類タスク照会 タスク ID を指定して、状態（処理中／成功／失敗）と結果を取得します。成功時は帳票タイプと信頼度が返ります。
API URL タブ 既存のエンドポイント一覧の末尾に、上記 2 件が読み取り専用で追加されます。

呼び出しの流れ

1AI分類（送信） に業務シーンとファイルを送り、分類タスク ID を受け取ります。

2AI分類タスク照会 を 1〜3 秒間隔で呼び出します。処理中の間は照会を続けます。

3成功なら帳票タイプと信頼度、失敗なら理由を取得して終了します。同じタスク ID を再度照会しても、分類は再実行されません。

注意事項 1 リクエストにつき 1 ファイル、50MB までです。形式は PDF、JPG、JPEG、PNG、TIF、TIFF に対応します。業務シーンは公開済みのものだけを指定できます。120 秒を超えると処理タイムアウトとして失敗します。結果のコールバック通知はなく、分類結果は案件や未集約ファイルには反映されません。
挿入位置 #admin-doctype-config 内の #doctype-impact の直後に id="doctype-p2"。
既存の Step1〜Step5 の本文は残し、変更点だけを Step 単位でまとめます（既存手順を書き換えるのではなく、差分を読めるようにする）。

ルール設定モジュール

帳票タイプ設定

二期追加機能 NEW

二期では、Step2 のフィールド表に HITL と マスク が追加され、Step3 で正常値範囲を設定できるようになります。

Step追加・変更主な画面
Step2フィールド単位の HITL（確認要否）フィールド表
Step2フィールド単位の マスクフィールド表
Step3正常条件（正常値範囲）処理ルール設定

Step2 確認要否（HITL）

フィールド／列ごとに HITL スイッチが追加されます。既定は ON です。ON の項目だけが人工確認の対象になり、OFF の項目は確認画面に表示されません。ただし、必須チェックと正常値検証は OFF でも適用されます。

Step2 マスキング

テキスト読取のフィールド表に マスク スイッチが追加されます。既定は OFF です。ON にしたフィールドは、Step3 処理ルールと Step5 効果テストに表示されません。マスタ照合やテキスト置換の対象からも外れます。

Step3 正常値範囲

処理ルール設定 の 正常条件 列で、OCR 値が正常値の範囲に入っているかを判定します。「範囲内」「<」「≤」「>」「≥」「列挙」から選び、処理ルールを適用した後の値を比較します。数値の閾値は、プロンプトで指定した抽出単位と同じ単位で入力します。マスタ照合とテキスト置換には正常条件を設定しません。範囲を外れた値は「正常値範囲を超えています」として人工確認の対象になります。

挿入位置 #admin-scene-config 内の #scene-impact の直後に id="scene-p2"。
図 前処理ノードの 1 枚のみ。範囲選択モード・メール通知・言語切替・Step1 は今回の対象外のため削除。

ルール設定モジュール

業務シーン設定

二期追加機能 NEW

二期では、前処理ノードに 画像不正検知 と 敏感情報検出（脱敏） が追加されます。画像回転・画像補正・画像整列は一期からある機能で、変更はありません。

追加内容
画像不正検知 PS検出／AI生成検出／帳票特徴検出／筆跡検出の 4 項目を個別に ON/OFF できます。不通過時は不正タイプを返して人工確認へ回します。
敏感情報検出 対象帳票にマスキングを実行します。フィールド単位の範囲は、帳票タイプ設定の Step2 マスクで決まります。

Step2 前処理ノード（画像不正検知・脱敏）

画像不正検知は、モジュール全体のスイッチと、PS検出／AI生成検出／帳票特徴検出／筆跡検出の 4 つの個別スイッチで構成されます。各項目は対象帳票を個別に選択でき、実行時は 4 項目が並列で動作します。1 つでも不通過なら不正タイプを返し、AI前処理確認に回します。

敏感情報検出（脱敏）は、画像回転・補正・整列が終わったあとに対象帳票へマスキングを実行します。フィールド単位の範囲は、帳票タイプ設定の Step2 マスクで決まります。

挿入位置 #operator-case-module 内の #case-operation の直後に id="case-p2"。

業務操作モジュール

案件一覧

二期追加機能 NEW

二期では、未集約ファイル が 要確認 と 無視可 の 2 つのサブタグに分かれ、関連失敗理由に応じて自動で振り分けられます。

サブタグ対象できること
要確認 分類失敗以外の未集約ファイル（案件不一致、処理タイムアウト、複数案件候補、関連付け中など） 実行案件集約、手動校准、プレビュー、削除
無視可 関連失敗理由が「分類失敗」のファイル 手動校准、プレビュー、削除

振り分けと関連案件ID

同じファイルの関連失敗理由が変わると、自動でもう一方のサブタグへ移動します。無視可 のファイルは 実行案件集約 の対象外です。

一覧には 関連案件ID 列が追加されます。同じソースファイル内で既に案件に紐づいたファイルの案件 ID を参照表示するもので、現在の行が紐づいたことを意味しません。紐づく案件がない場合は空欄です。

無視可の保持期間

無視可 のファイルは 7 日を過ぎると一覧から論理的に除外されます。元の影像は削除されません。

挿入位置 #operator-task-module 内の #task-operation の直後に id="task-p2"。

マイタスク

二期追加機能 NEW

二期では、AI 前処理のあとに「AI前処理確認」タスクが追加され、人工確認ルールも 7 項目に拡張されます。

AI前処理確認タスクの発生条件

いずれかに該当するとタスクが起案され、ファイルの状態が「前処理確認中」になります。該当しない場合はタスクを作らず、ワークフローは先へ進みます。

ワークフロー段階対象処理発生条件実行ページのタグ
案件集約ファイル分類分類の信頼度が Step1 の閾値未満分類
案件集約画像分割分割の信頼度が閾値未満分割
AI前処理画像整列整列の信頼度が閾値未満、または整列キーが未取得整列
AI前処理画像不正検知判定が不通過画像不正
AI前処理敏感情報検出サブ機能が有効で、検出が完了敏感情報

実行ページ

左に論理ページのサムネイル、右に帳票ファイルの一覧を表示します。帳票ファイルを選ぶと、左はそのファイルのページだけに絞り込まれます。

  • 並べ替え：ファイル内のページ順をドラッグで変更します。
  • 拡大：80% 幅のドロワーで表示します。回転はプレビューのみです。
  • 削除：誤分割したページを削除します。主帳票の最後の 1 ページは削除できません。
  • 展示名：サムネイル下のプルダウンで所属ファイルを変更します。
  • 新規分類：未分類のページを新しい帳票ファイルにまとめます。
  • 自動採番：同じ帳票タイプが複数ある場合、「診療明細書1」「診療明細書2」のように連番を付けます。

画像編集ドロワー

サムネイルの「画像編集」から、分割・マスキング・不正の 3 タブを開きます。分割は診療明細書、不正は診断書と診療明細書が対象です。分割では親ページ配下のサブページをまとめて確認・確定できます。マスキングでは黒塗り領域を追加・調整します。不正では命中したサブ分類ごとに枠を確認し、必要に応じて再検出します。

人工確認ルール（七項目）

読取モデル設定 のポップアップで、人工確認の条件を 7 項目から選べます。HITL が ON のフィールドだけが対象です。既定では ⑥ と ⑦ にチェックが入っています。

番号条件対象
①信頼度が閾値未満OCR／OCR 補完
②複数モデルの結果が不一致OCR
③マスタ照合の類似度が低いマスタ照合
④マスタ照合の結果が空マスタ照合
⑤マスタ照合の信頼度が低いマスタ照合
⑥正常値範囲を超えていますQR 値を含む全経路
⑦低信頼度かつ正常値範囲を超えていますOCR／OCR 補完

システム設定モジュール

利用量統計

二期では、システム設定に「利用量統計」が追加されます。7 つの課金ノードの帳票枚数と、大模型の token 消費を確認できます。

機能説明

案件の処理で課金対象になるノードを 7 種類に分け、処理が成功した分だけを集計します。

課金ノード単位計上の条件
案件集約ファイル処理が成功したとき
AI前処理ファイル回転・補正・整列などの通常の前処理が完了したとき（画像不正・敏感情報は含みません）
OCR抽出ファイル処理が成功したとき
データマッピング案件成功し、案件内のパラメータを実際に参照したファイル
AI検証案件データマッピングと同じ
画像不正検出ファイル当該実行で有効かつ完了したとき
敏感情報検出ファイル画像不正検出と同じ

失敗した実行は課金されません。同じ案件・ファイル・ノードの組み合わせは 1 件にまとめ、枚数が増えた場合だけ更新します。

画面操作

1システム設定 → 利用量統計 を開きます。

2利用量一覧、実行履歴、モデル呼び出し明細 のタブを切り替えます。期間・案件ID・ファイル名・処理ノードで絞り込めます。

3モデル呼び出し明細 タブで、ノード種別ごとの入力・出力 token を確認します。

4エクスポート をクリックすると、現在の絞り込み条件で CSV を出力します。

関連影響

タブ内容主な列
利用量一覧課金単位ごとに 1 行案件ID、業務シーン、ファイル名、帳票枚数、処理ノード、処理開始日時、処理完了日時
実行履歴実行ごとに 1 行（失敗も含む）実行結果、集計対象、帳票枚数、処理開始日時、処理完了日時
モデル呼び出し明細大模型の token 消費ノード種別、使用モデル、入力トークン、出力トークン、呼び出し元、呼び出し開始日時、モデル応答日時
注意事項 画像不正検出と敏感情報検出は AI前処理の子機能ですが、別の課金ノードとして表示されます。モデル呼び出し明細はファイルとは紐づきません。AI アシストによる呼び出しは案件ID が「—」になります。再実行しても、枚数が増えない限り利用量一覧は増えません。各タブの CSV は現在の絞り込み条件で、ページングに関係なく全件を出力します。
