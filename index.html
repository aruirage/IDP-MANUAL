NeosAI IDP マニュアル

NeosAI IDPは、保険金請求などの業務書類を案件単位に集約し、AI-OCR、業務ルール、AIによる検証、担当者による確認を組み合わせて処理するIntelligent Document Processing（IDP）システムです。

管理者があらかじめ設定したルールに基づき、複数種類の帳票を自動で分類・読み取り・検証します。業務担当者は 案件一覧 と マイタスク で確認・修正・出力処理を行います。

8 帳票タイプ設定 Step1 帳票分類信頼度閾値 分類の信頼度が閾値を下回る場合に、低信頼度としてマニュアル確認の対象にします。
9 帳票タイプ設定 確認要否（HITL） フィールド／列ごとに、マニュアル確認の要否を設定できます。OFF でも必須チェックは適用されます。正常値の比較は、マニュアル確認ルールで ⑥⑦ を選んだ場合だけ行います。
10 帳票タイプ設定 マニュアル確認ルール（七項目） Step2 の読み取りモデル設定で、OCR抽出確認に出す条件を 7 項目から選べます。HITL が ON のフィールドだけが対象です。
11 帳票タイプ設定 正常値の範囲 範囲判定・比較・列挙によって値が正常かどうかを判定し、範囲外の値は確認対象とします。処理ルール適用後の値が対象です。
12 帳票タイプ設定 マスキング フィールド単位でマスキングを設定すると、そのフィールドはOCR抽出の対象外になります。下流の処理ルール・効果テストからも除外されます。
13 帳票タイプ設定 QR 読み取り（LIAJ 診断書専用） LIAJ 診断書専用。複数 QR を左から連結し、設定したフィールド順に値を割り当てます。値の数が一致しない場合は全体を OCR で読み取ります。
14 帳票タイプ設定 Step5 効果テスト 各項目の読み取りソース（QR読み取り／OCR読み取り）、範囲結論、要確認、マスクの反映を確認します。
15 業務シーン設定 画像不正検知 前処理ノードで、PS／AI生成／帳票の特徴／筆跡の4項目を個別に判定します。基準未達はマニュアル確認へ回します。
16 業務シーン設定 範囲選択モード キャンバス上で複数ノードを矩形で囲み、まとめて移動・コピー・削除できます。開始ノードは対象外です。
17 業務シーン設定 通知メールチャネル 通知ルールでは、システム通知とメールを複数選択でき、メールの送信先も指定できます。

ルール設定モジュール

保険金請求業務を想定した場合、設定は次の順序で進めることを推奨します。 モデル → API → マスタデータ → 帳票タイプ → 業務シーン → データマッピング → AI検証 です。

各画面での設定は、次の順序で進めます。モデル設定 → API設定 → マスタデータ設定 → 帳票タイプ設定 → 業務シーン設定 → データマッピング設定 → AI検証設定。本マニュアルでは、各機能モジュールの操作手順に加え、画面上では分かりにくい設定の適用タイミングについても説明します。ロール詳細は ロール設定 を参照してください。

ルール設定モジュール

モデル設定

本モジュールでは、NeosAI IDP で利用するモデルリソースを一元管理します。OCR抽出、AI検証、データマッピングで使うモデルを、用途ごとに割り当てて管理します。

機能説明

権限：本機能は admin が設定します。操作員はモデル接続情報や用途の割り当てを変更できません。公開済みの業務シーンを通じて、設定済みモデルによる処理結果を利用します。

設定ロジック：API 接続 では外部モデルプロバイダへの接続情報を登録し、用途割当 では機能ごとに使用するモデルを指定します。OCR抽出 のみ複数モデルを選択でき、主モデルの認識結果を検証するために使用します。その他の用途では、用途ごとに1つのモデルを選択します。プロバイダとモデルが対応している場合のみ シンキングレベルも設定できます。

P2追加機能 NEW

P2では、API 接続 に シンキングレベルが追加されます。プロバイダとモデルが対応している場合のみ推論の深さを指定でき、後続の大模型呼び出しに反映されます。

シンキングレベル

項目内容
表示条件プロバイダとモデルの両方がシンキングレベルに対応している場合だけ、接続の追加・編集画面に表示されます。モデルによっては表示されない仕様です。OpenAI 互換のカスタム接続では表示されない仕様です。
選択肢選択肢はプロバイダ・モデルごとに異なります（例：OpenAI／Anthropic は Low・Medium・High、Google Gemini は Minimal・Low・Medium・High）。
必須対応しているプロバイダ・モデルでは必須です。未選択のままでは保存できません。
一覧表示API 接続 の一覧に シンキングレベル 列が追加されます。非対応の接続は「—」と表示されます。
適用範囲保存後に新しく開始されるモデル呼び出しから反映されます。既存の接続は Low が初期値です。

設定手順

1業務ルール設定 → モデル設定 の API 接続 タブで、対象の接続の 編集 をクリックします。

2対応している プロバイダ とモデルを選ぶと シンキングレベル が表示されます。値を選び、保存 して 接続テスト を実行します。

注意事項 プロバイダやモデルを切り替えると選択肢が更新されます。非対応のプロバイダまたはモデルに変更した場合はシンキングレベルが非表示になり、保存時にも書き込まれません。

用途割当 › AI前処理・座標抽出

用途割当に AI前処理 と 座標抽出 が追加されました。どちらも 1 つのモデルを選ぶ単一選択です。AI前処理 は AI前処理ノード内の大模型呼び出しで使用し、案件集約 の割当を自動では引き継ぎません。

  • AI前処理：画像不正検知など、AI前処理ノード内の大模型呼び出しに使用します。
  • 座標抽出：帳票内の項目位置（座標）の特定に使用します。
注意事項 AI前処理 が未割当のままでは用途割当を保存できません。P2 より前に保存した設定は引き継がれないため、アップグレード後に個別にモデルを選択してください。

ルール設定モジュール

API設定

本章では、外部システムから NeosAI IDP を呼び出すための Open API を管理します。設定画面は 通知先URL、APIキー管理、API URL の 3つのタブです。パス、フィールド英語名、エラーコードは専用の API 接続文書を参照してください。

機能説明

権限：本機能は admin が設定します。操作員は API 設定を編集せず、画面操作または公開済み業務シーンに基づく処理結果を利用します。

設定ロジック：APIキー管理 では外部システムが使う API キーを発行・管理します。通知先URL では、プラットフォームが外部へ送るコールバック先と 署名鍵 を設定します。API URL では、ファイルアップロード、案件一覧照会、バッチ別案件照会、追加資料アップロード、一括エクスポート、エクスポートタスク照会、AI分類依頼、AI分類タスク照会のエンドポイントを確認し、コピーできます。AI分類は 1 ファイルの帳票タイプだけを判定し、このAPIでは、案件の作成やワークフローの起動は行いません。

利用タイミング：画面から手動アップロードする代わりに、社内システムや RPA から案件投入、進捗照会、補件、一括出力を行う場合に利用します。リクエストは API キーで認証します。

画面操作

1業務ルール設定 → API設定 を開き、APIキー管理 で登録済みの API キーと有効状態を確認します。新規発行する場合は +API キー をクリックします。

2+API キー のダイアログで 名称 を入力し、有効期限 を 7日間 / 1年 / 3年 から選択して発行します。

3通知先URL タブで 外部通知設定 を確認します。通知先URL と 署名鍵 を変更する場合は 編集 をクリックします。

4編集画面で 通知先URL を入力します。署名鍵 は 生成 で発行し、保存 します。

5API URL タブで、ファイルアップロード、案件一覧照会、バッチ別案件照会、追加資料アップロード、一括エクスポート、エクスポートタスク照会のエンドポイントを確認します。コピーアイコンで URL を取得できます。リクエスト形式などの詳細は専用の API 接続文書を参照してください。

Step2 の 読み取りモデル設定 に マニュアル確認ルール が新設され、7 項目すべてを選択できるようになりました。Step2 のフィールド表で HITL が ON のフィールドだけが対象です。このルールは OCR抽出確認 に適用されます。AI前処理確認 の対象は、前処理の検出結果（分類・分割・画像不正・敏感情報）で決まります。

マニュアル確認の対象かどうかは、次の順で判定します。

Step2 QR 読み取り（LIAJ 診断書専用）

複数QR読み取り スイッチは LIAJ 診断書 専用の設定です。ほかの帳票タイプには適用されません。既定は OFF で、OFF のときは OCR のみで読み取ります。

ON にすると、最初のスキャンで帳票下部の複数コードを検出し、検出された数だけ左から順にデコードします。データコードは $ を含むものだけを対象とし、$ と ^ で分割して、フィールド表の順に 1 フィールド 1 値を書き込みます。

フィールドは、QR のデータ項目と同じ順序で並べる必要があります。QR から取得できた値の数が、設定したフィールド数と一致すれば QR 値で全体を埋めます。一致しない場合は、その帳票全体を OCR で読み取ります（一部のフィールドだけ QR 値を書き込むことはしません）。

フィールドが多い場合は、Step2 のテンプレートをダウンロードし、一括インポートでまとめて設定します。

200 フィールドを超える場合 AI自動生成（プロンプトと正解サンプルの生成）は、フィールド数が多いとコンテキスト超過で読み込めないことがあります。200 フィールドを超える場合は AI自動生成 を使わず、テンプレートの一括インポートで設定してください。Step3 の AIマッチング にはこの制限はありません。

OCR抽出確認OCR 値の信頼度が低い、モデル間で結果が一致しない、マスタ照合の候補が確定できない場合。帳票画像と抽出値を照合し、テキスト・テーブル・マスタ候補を確認、必要に応じて修正します。OCR抽出完了 で後続ノードへ進みます。補件または案件中止を選択することもできます。
AI検証確認AI検証ノード実行後、1 件以上の検証ルールが 確認待ち となった場合（必須フィールド不足、必要書類不足、標準データ不整合、テキスト検証 NG、データ検証 NG、署名・印影不足など）。AI検証要約結果 で当該案件の実行済み検証ルールをすべて確認します。緑の 確認済み は確認済みのルール、青の 確認待ち はマニュアル確認対象です。要確認ルールについて判定理由・対象帳票・フィールドを確認し、確認済み・補件・案件中止を選択します。AI検証完了 で後続ノードへ進みます。補件時は案件一覧から追加書類を受け付けます。
エクスポートワークフローの確認処理が完了し、出力可能になった場合。業務シーン設定の出力項目に沿って内容を確認し、結果を提出します。提出後、案件は エクスポート済 として扱われます。

画面操作

1未対応 / 対応済 でタスクを切り替え、タスク種別・案件キー・業務シーン・業務 key で絞り込みます。未対応行の 対応 で実行ページへ進みます。

2OCR抽出確認：一覧の 対応 から実行画面を開き、左の帳票プレビューと右の テキスト読み取り / テーブル情報読み取り で抽出値を確認・修正します。項目位置を非表示 を ON にすると切り出し画像と帳票上の対応領域が連動します。マスタ照合フィールドでは 類似度検索 候補から正規値を選べます。確認後、フッターの OCR抽出完了 で後続ノードへ進みます。

マニュアル確認ノードとの連動（OCR / AI検証共通） 実行画面フッターの OCR抽出完了 / AI検証完了 は、ワークフローキャンバス上の マニュアル確認 ノードの 完了 出口に対応し、後続ノードへ進みます。前処理のマニュアル確認タスクは本期対象外です。補件 は 補件 出口へルーティングされ、キャンバスで設定した前段ノード（例：OCR抽出）へ戻ります。案件は 補件 状態となり、案件一覧 から追加書類をアップロードします。案件中止 はキャンバス上では接続せず、選択時に現在のワークフローインスタンスを終了します（案件自体は再実行可能）。保存 は進捗のみ保存し、出口は確定しません。

3AI検証確認：AI検証要約結果 タブで実行済み検証ルールを確認します。緑の 確認済み は確認済みのルール、青の 確認待ち はマニュアル確認対象です。必須フィールド・必要書類・標準データ整合性・テキスト検証・データ検証・署名・印鑑検証 ごとに判定理由と対象帳票を確認し、問題なければ 確認済み に更新します。すべて処理したら AI検証完了 で後続ノードへ進みます。

4エクスポート：出力形式（CSV / JSON / EXCEL）を選び、左の エクスポート対象 ツリーと右のプレビューで出力内容を確認します。処理結果をエクスポート で結果ファイルを出力し、必要に応じて 前処理済み ZIP を取得したうえで エクスポート完了 をクリックします。

5割当 でタスク担当者を変更（操作管理者のみ）。

実行ページ

タスク一覧の 対応 から実行ページを開きます。まず右の 帳票ファイル で自動分類されたファイルを確認します。分類を変更する場合は、左のページ一覧のサムネイル下にある展示名のプルダウンで所属ファイルを変更します。次に、サムネイルをクリックするとそのファイルの内部に入り、画像編集ドロワーが開きます。右上には 要確認 の件数が表示されます。

  • 未確認のページ：赤い枠と 確認待ち が付きます。確認待ち を押すと、そのページの確認が完了します。
  • タグ：分割／画像不正／敏感情報 が左下に表示されます。複数該当する場合は並んで表示されます。
  • 並べ替え：すべてのページ 表示では不可、ファイルを選んだ状態でのみドラッグで変更できます。
  • 削除：誤分割したページを削除します。主帳票の最後の 1 ページは削除できません。
  • 展示名：サムネイル下のプルダウンで所属ファイルを変更します。未分類のページは 未分類 と表示されます。
  • 新規帳票タイプ：+ 新規帳票タイプ で空のファイルを作り、ページを割り当てます。
  • 自動採番：同じ帳票タイプが複数ある場合、「診療明細書1」「診療明細書2」のように連番を付けます。

フッターは 閉じる／案件中止／補件／保存／前処理完了 です。保存 は進捗だけを保存し、前処理完了 はすべて確認済みのときだけ押せます。

画像編集ドロワー

サムネイルをクリックすると画像編集ドロワーが開きます。既定は マスキング タブで、分割／不正 に切り替えられます。右側の 子ページ 一覧で対象を切り替え、上部のツールバーで拡大・回転・回転を保存を操作します。

分割：子ページの追加・削除、分割枠の移動・サイズ変更ができます。分割は診療明細書が対象です。複数の子ページがある場合は、右の子ページ一覧で切り替えて確認します。

マスキング：黒塗り領域の追加・削除・サイズ変更ができます。キャンバス上をドラッグすると領域を追加でき、四角のハンドルでサイズを変更します。右の領域一覧から、画面外の領域も削除できます。

不正：命中したサブ分類（PS加工疑い／テンプレート不一致疑いなど）ごとに枠を確認します。不正領域は変更できず、閲覧のみです。必要に応じて 再検出 を子ページ単位で実行します。

回転：画像は回転でき、回転を保存 で角度を保存します。

課金ノード単位計上の条件
